# 博士的破局点：让认知在正确的时间发力

## 字幕正文

上午好啊，出门之前聊一个小的话题，就是读到博士的人往往有更多的痛苦。

这个痛苦呢，是来自于形成了一套复杂的认知体系。

而这套认知体系呢，它会带运用到你的生活的很多方面。就是你当你拥有了一个东西，你会不自觉地运用它，而且你有时候无法选择，因为它已经成为了你的一套思考习惯。

呃，它已经嵌入到你的这个日常生活中看待事物的视角啊，然后分析事物啊，是无法控制的，但这套认知系统其实是非常耗能的。

因为当你看到一件事情要不要做的时候，你会忍不住的从呃，它的利弊角度啊，然后从它的建立边界条件啊，从它的这个风险的这种程度啊，从收益的程度各方面，你会用一套你在读博期间形成的认知体系去带入运算，这条运算非常耗能。

而这个有相当多的博士，他们在市场化的过程中会碰壁或者说不会就是不顺利，其中有一个原因就是他们的这种无效耗能太多了。

这个能量都在这种不自觉的带入中被消耗掉了，而实际上在市场上赚钱，它往往是一个搏概率的过程，就是它要某种时候有的时候是要行动快于脑速的，就是你要通过不断的这个尝试，然后去找到那个有效市场在哪儿。

但通过这种复杂思维训练的人，他往往是先带入说我对做这些事情的成率，概率，优点缺点各个方面完成了一套自动化的分析。

注意啊是自动化的，有的时候不是你你主动想要这样去分析。

然后完成这一套之后耗能之后，你最后做出的决定是，唉呀，这个事情不要做了，或者是这个事情做起来风险太大了，有各种这种担忧各种忧虑。

然后通过各种的这种理性分析之后就放弃了。

但事实上在市场上取得大量成功的人，尤其是学历并不高的人，他们获得成功的原因是他们用行动去试验这个市场，而不是用预设的一套思维框架去实验这个市场。

所以他们往往其实成功率比许多有着更高认知的博士成功率更高。

然而呢，如果我们再去看的话，也有大量的这种高学历的人，他们获得了市场的成功，且获得更大的市场的成功。

而且往往如果是这些高学历的人敢于出手的话，他们获得的成功率会更高，为什么呢？是因为他们懂得在什么时机上介入这种复杂，呃介入这种复杂的思考是能够提高成功的概率的。

注意哈，这这一点是很重要，就是这些具有更高认知的人，他们去创业啊，或者去从事呃，某些事业的成功率更高，是在于他们知道在什么环节，什么阶段去介入这种复杂性的系统性的思考是有效的。

而不是过早介入，把自己的能量和意志力都消耗掉之后，最终放弃了这个行动。

如果能够把握好这个分寸，我相信会有更多的博士在开创自己的事业的时候，在进入产业界的时候能够获得成功。

我是白鱼，关注我，和我一起持续进化。
